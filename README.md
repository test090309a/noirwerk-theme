# 

# \## ✨ Features

# 

# \- 🎨 \*\*Dark \& Minimalistisch\*\* – Reduziertes, elegantes Design mit roten Akzenten

# \- 🎬 \*\*Hero-Section\*\* – Video-Hintergrund mit Canvas-Regen-Effekt

# \- 📜 \*\*Smooth Scrolling\*\* – Mit Lenis und GSAP Animationen

# \- 🖱️ \*\*Custom Cursor\*\* – Individueller Cursor mit Hover-Effekten

# \- 📧 \*\*Eigenes Kontaktformular\*\* – Mit Datenbank-Speicherung

# \- 📊 \*\*Admin-Dashboard\*\* – Kontaktanfragen verwalten

# \- 📱 \*\*Responsive\*\* – Optimiert für alle Bildschirmgrößen

# \- 🎯 \*\*Block-Theme kompatibel\*\* – Funktioniert mit WordPress 6.0+

# 🛠️ Technologien

# Bereich	Technologie

# Backend	WordPress 7.0.3, PHP 8.3

# Frontend	HTML5, CSS3, Vanilla JavaScript

# Animationen	GSAP 3.12.5, Lenis 1.1.14

# Datenbank	MySQL / MariaDB

# Farben ändern

# 

# css

# :root {

# &#x20;   --black: #000000;

# &#x20;   --font: 'IBM Plex Mono', monospace;

# }

# Ersetze die Google Fonts URL in der functions.php:

# 

# php

# wp\_enqueue\_style('google-fonts', 'https://fonts.googleapis.com/css2?family=YOUR\_FONT\&display=swap');
