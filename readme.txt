== Description ==

Noirwerk ist ein dunkles, minimalistisches Theme für digitale Systeme, kreative Studios und Portfolios. Es bietet:

* 🎨 **Dark & Minimalistisch** – Reduziertes Design mit roten Akzenten
* 🎬 **Hero-Section** – Video-Hintergrund mit Canvas-Regen-Effekt
* 📜 **Smooth Scrolling** – Mit Lenis und GSAP Animationen
* 🖱️ **Custom Cursor** – Individueller Cursor mit Hover-Effekten
* 📧 **Eigenes Kontaktformular** – Mit Datenbank-Speicherung
* 📊 **Admin-Dashboard** – Kontaktanfragen verwalten
* 📱 **Responsive** – Optimiert für alle Bildschirmgrößen
* 🎮 **DOOM Easter Egg** – Geheimes Spiel im Theme

== Installation ==

1. Lade das Theme als ZIP herunter
2. Gehe zu **Design → Themes → Installieren**
3. Lade die ZIP-Datei hoch
4. Aktiviere das Theme
5. Erstelle Menüs unter **Design → Menüs**
6. Konfiguriere die Startseite unter **Einstellungen → Lesen**

== Frequently Asked Questions ==

= Wie erstelle ich das Kontaktformular? =

Das Theme enthält ein eigenes Kontaktformular. Die Nachrichten werden in der Datenbank gespeichert und im Admin-Dashboard unter **Kontaktanfragen** angezeigt.

= Wie starte ich DOOM? =

Tippe auf der Tastatur **DOOM** – dann öffnet sich das geheime Spiel!

= Welche Schriftart wird verwendet? =

Das Theme verwendet die Schriftart **IBM Plex Mono** von Google Fonts.
